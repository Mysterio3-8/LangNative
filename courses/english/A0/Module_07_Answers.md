# Модуль 07: Ключи к контрольной работе
## Ответы и разбор теста

| Вопрос | Ответ | Пояснение |
|---|---|---|
| **1** | **B** | Прилагательные ставятся строго перед существительным: *a new red car*. |
| **2** | **B** | Фраза *orange umbrella* начинается с гласного звука [ɒ], поэтому требуется артикль **an**. |
| **3** | **B** | Для близкого предмета в единственном числе используется **this**. |
| **4** | **B** | После шипящего звука [tʃ] пишется окончание **-es**: *watches*. |
| **5** | **B** | Во множественном числе артикль *a* исчезает: *These are books*. |
| **6** | **B** | Для предметов вдалеке во множественном числе используется **those**: *Those cars are green*. |
| **7** | **C** | В слове *receipt* [rɪˈsiːt] буква **p** немая. |
| **8** | **C** | Существительное *credit cards* во множественном числе, поэтому форма глагола — **are**. |
| **9** | **C** | Предлог **on** означает «на горизонтальной поверхности». |
| **10** | **B** | Слово *bus* заканчивается на -s, поэтому во множественном числе принимает **-es**: *buses*. |
| **11** | **A** | Стандартный вопрос: *What colour is your backpack?* |
| **12** | **C** | *These* = эти (близко, множественное число): *Это мои новые билеты*. |
| **13** | **B** | В слове *hour* первая буква *h* не читается, звук гласный [aʊə], поэтому пишем **an hour**. |
| **14** | **A** | На вопрос *What is that?* отвечаем указанием на предмет: *It is a taxi*. |
| **15** | **B** | В варианте B всё верно (*a black car*). В А лишний артикль, в C должно быть *an old*, в D — *These are*. |
