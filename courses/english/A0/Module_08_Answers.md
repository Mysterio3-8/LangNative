# Модуль 08: Ключи к контрольной работе
## Ответы и разбор теста

| Вопрос | Ответ | Пояснение |
|---|---|---|
| **1** | **B** | Множественное число слова *child* — **children** (неправильное существительное). |
| **2** | **B** | Для мужчины (*He*) притяжательное местоимение — **his** (его). |
| **3** | **B** | Притяжательный падеж образуется с помощью апострофа и буквы s: **Mark's car**. |
| **4** | **B** | С местоимениями *he, she, it* используется форма **has got**. |
| **5** | **B** | Отрицание от *have got* — **haven't got** (*I haven't got a dog*). |
| **6** | **B** | Сын — **son** (слово *sun* пишется через u и означает «солнце»), дочь — **daughter**. |
| **7** | **B** | Родители — **parents** (мама и папа вместе). |
| **8** | **A** | Для местоимения *We* (мы) притяжательная форма — **our** (наш). |
| **9** | **B** | В слове **mother** звук [ð] звонкий межзубный, как и в слове *this*. В словах *three, thanks, think* звук глухой [θ]. |
| **10** | **A** | Краткий утвердительный ответ на вопрос с *Have you got...?* — **Yes, I have**. |
| **11** | **B** | Сестра мамы — это тётя (**aunt**). |
| **12** | **A** | *Her husband's name is Alex* — грамматически безупречно (притяжательное her + притяжательный падеж husband's). |
| **13** | **B** | *They haven't got children* переводится как «У них нет детей». |
| **14** | **B** | Противительный союз «но» в английском языке — **but**. |
| **15** | **B** | В варианте B всё верно (*He's got three children and a black cat*). |
