# Модуль 12: Ключи к финальному экзамену A0
## Полные ответы и методический разбор

| № | Ответ | Тема и правило |
|---|---|---|
| **1** | **B** | Порядок букв алфавита: J, **K**, L. |
| **2** | **B** | Буквосочетание sh всегда передаёт глухой шипящий звук **[ʃ]**. |
| **3** | **C** | В слове **this** звук [ð] звонкий межзубный (в *thanks, three, think* — глухой [θ]). |
| **4** | **B** | В открытом слоге с немой буквой e на конце буква a читается как дифтонг **[eɪ]** (*name*). |
| **5** | **B** | До 12:00 дня используется приветствие **Good morning!** |
| **6** | **B** | Существительное *my mother* (женский род, ед.ч.) заменяется местоимением **She**. |
| **7** | **C** | *Tom and Anna* = они (*They*), форма глагола to be — **are**. |
| **8** | **B** | *Forty-five* = **45**. |
| **9** | **B** | Возраст выражается строго через глагол to be: **I am 25 years old**. |
| **10** | **C** | Точка в адресах электронной почты произносится как **dot**. |
| **11** | **B** | Слово **apple** начинается с гласного звука [æ], поэтому нужен артикль **an**. |
| **12** | **C** | Для далёких предметов во множественном числе используется указатель **those**. |
| **13** | **B** | Согласная + y переходит в **-ies**: *city ➔ cities*. |
| **14** | **A** | Брат отца — это дядя (**uncle**). |
| **15** | **B** | Для женщины притяжательное местоимение — **her** (*her husband*). |
| **16** | **B** | С местоимением *He* используется форма **has got**. |
| **17** | **B** | После среды (*Wednesday*) идёт четверг (**Thursday**). |
| **18** | **C** | С точным временем всегда употребляется предлог **at**: *at 6:00 p.m.* |
| **19** | **A** | Безличные предложения о погоде строятся по формуле: **It is windy and cold today**. |
| **20** | **B** | *Wake up* переводится как «просыпаться». |
| **21** | **B** | В Present Simple для местоимения *They* глагол используется в начальной форме: **work**. |
| **22** | **C** | Отрицание глагола know: **I don't know**. |
| **23** | **C** | Вопрос в Present Simple к местоимению you строится через вспомогательный глагол Do: **Do you speak English?** |
| **24** | **B** | После модального глагола can смысловой глагол ставится без частицы to: **Can you help me, please?** |
| **25** | **C** | **Cheese** (сыр) — вещественное неисчисляемое существительное. |
| **26** | **B** | Самая вежливая форма заказа: **I'd like a cappuccino, please**. |
| **27** | **C** | Для одного предмета вопрос о цене: **How much is this croissant?** |
| **28** | **C** | Союз противопоставления — **but** («Мне нравится Лондон, НО он очень дорогой»). |
| **29** | **A** | Устойчивая вежливая формула передачи предметов: **Here you are**. |
| **30** | **B** | Предложение **B** абсолютно безошибочно. В А (*childs, live*), в C (*These car*), в D (*Where you are from* нарушен порядок слов). |
