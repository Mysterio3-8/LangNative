# Модуль 10: Ключи к контрольной работе
## Ответы и разбор теста

| Вопрос | Ответ | Пояснение |
|---|---|---|
| **1** | **C** | В Present Simple для *I* глагол стоит в чистом виде: **I live in Madrid**. Никакой глагол *am* перед действием не ставится. |
| **2** | **B** | Отрицание глаголов действия строится через don't: **I don't understand**. |
| **3** | **C** | Для вопроса к *you* в Present Simple используется вспомогательный глагол **Do**: *Do you like coffee?* |
| **4** | **B** | Краткий ответ повторяет вспомогательный глагол вопроса: *Do you...? — Yes, I do*. |
| **5** | **B** | В слове **know** [nəʊ] буква k немая. |
| **6** | **A** | Вежливая форма заказа: **Can I have a coffee, please?** (без частицы to). |
| **7** | **B** | С местоимением *We* используется отрицание **don't**: *We don't speak Russian*. |
| **8** | **C** | Вопрос о месте проживания: **Where do you live?** |
| **9** | **B** | В British English слово **can't** произносится через глубокий долгий гласный [kɑːnt]. |
| **10** | **B** | После модального глагола can/can't смысловой глагол ставится в начальной форме без to: *I can't **find** my passport*. |
| **11** | **A** | Вопрос **What do you do?** переводится «Кем вы работаете / Чем занимаетесь?». |
| **12** | **B** | *Do you accept credit cards?* — Вы принимаете кредитные карты? |
| **13** | **B** | С названиями языков всегда используется глагол **speak**: *speak languages*. |
| **14** | **B** | *I don't eat meat* означает «Я не ем мясо». |
| **15** | **B** | Вариант B (*Do you live near the station?*) полностью грамматически корректен. |
