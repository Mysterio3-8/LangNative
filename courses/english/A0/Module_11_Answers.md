# Модуль 11: Ключи к контрольной работе
## Ответы и разбор теста

| Вопрос | Ответ | Пояснение |
|---|---|---|
| **1** | **B** | Слово **bread** (хлеб) неисчисляемое, поэтому артикль *a* с ним не употребляется. |
| **2** | **B** | Вежливая форма заказа: **I'd like a coffee, please** (сокращение от *I would like*). |
| **3** | **B** | *For here or to go?* переводится «Здесь будете кушать или заберёте с собой?». |
| **4** | **A** | Для одного предмета в единственном числе используется форма **is**: *How much is this sandwich?* |
| **5** | **B** | Цены в разговорном английском называют парой чисел: $5.80 = **five eighty**. |
| **6** | **B** | Негазированная вода — **still water**. |
| **7** | **B** | Устойчивая фраза «Сдачи не надо»: **Keep the change**. |
| **8** | **C** | Оплата картой выражается предлогом **by card** (а наличными — *in cash*). |
| **9** | **B** | С местоимением *We* отрицание строится через вспомогательный глагол **don't**: *We don't eat meat*. |
| **10** | **B** | В слове **receipt** [rɪˈsiːt] буква **p** немая. |
| **11** | **B** | Стандартный вежливый ответ: **That's all, thank you** (Это всё, спасибо). |
| **12** | **B** | Газированная вода — **sparkling water**. |
| **13** | **A** | Для существительного во множественном числе используется глагол **are**: *How much are these bananas?* |
| **14** | **B** | Счёт в ресторане в Великобритании — **bill** (в США также используется *check*). |
| **15** | **A** | Вариант A (*Can I have a glass of water, please?*) безупречен. В B неисчисляемое во множественном числе, в C неверно согласован глагол, в D должно быть *doesn't*. |
