# Модуль 09: Ключи к контрольной работе
## Ответы и разбор теста

| Вопрос | Ответ | Пояснение |
|---|---|---|
| **1** | **B** | В слове **Wednesday** [ˈwenz.deɪ] первая буква d немая. |
| **2** | **C** | С днями недели всегда употребляется предлог **on**: *on Friday*. |
| **3** | **A** | С точным временем употребляется предлог **at**: *at 7:30 p.m.* |
| **4** | **B** | *p.m.* обозначает время после 12 дня: *2:00 p.m.* = 14:00 (2 часа дня). |
| **5** | **C** | Слово *o'clock* используется только для круглых часов (*five o'clock*), с минутами (*eight thirty*) его говорить нельзя. |
| **6** | **B** | Устойчивое сочетание со словом night — предлог **at night**. |
| **7** | **B** | Стандартный вопрос носителей о погоде: *What is the weather like today?* |
| **8** | **B** | С сезонами года используется предлог **in**: *in summer, in winter*. |
| **9** | **B** | Все приёмы пищи в английском сочетаются с глаголом have: **have breakfast**, have lunch, have dinner. |
| **10** | **B** | Четверг — **Thursday** [ˈθɜːz.deɪ]. *Tuesday* — вторник. |
| **11** | **A** | Безличные предложения о погоде строятся строго с местоимением it: *It is sunny and warm*. |
| **12** | **C** | *Wake up* — проснуться (открыть глаза), *get up* — встать с постели. |
| **13** | **B** | С днями недели употребляется предлог on: *See you on Saturday!* |
| **14** | **B** | *Ten forty-five* = 10:45. |
| **15** | **C** | В варианте C всё верно (*We have dinner at 7:00 p.m. on weekdays*). |
