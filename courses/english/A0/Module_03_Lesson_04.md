# Модуль 03: Гласные и чтение слов
## Урок 4: Чтение CVC-слов и слияние звуков (Блендинг)

### 1. Цель
К концу урока я могу:
- Использовать технику **блендинга (sound blending)**: мгновенно соединять согласный + гласный + согласный в единое слово без пауз.
- Читать без запинки любую таблицу из 30+ базовых CVC-слов с гласными A, E, I, O, U.
- Узнавать первые цельные слова в мини-фразах.

### 2. Словарь и фонетика: Золотая таблица 5 гласных в закрытом слоге
Вспомним 5 гласных букв в закрытом слоге:
1. **A = [æ]** (широкий): *cat, hat, bat, bag, man, pan*
2. **E = [e]** (узкий): *bed, pen, ten, red, pet, net*
3. **I = [ɪ]** (краткий расслабленный): *sit, pin, big, six, win, lip*
4. **O = [ɒ]** (краткий овал): *hot, dog, box, fox, top, pot*
5. **U = [ʌ]** (краткий нейтральный): *cup, bus, sun, run, nut, bug*

**Как работает слияние (Blending):**
Не читайте буквы по отдельности «Б... Э... Т...»! Соединяйте первые два звука [bæ], а затем добавляйте финал [t] ➔ **bat**.

### 3. Практические задания (8 типов)
1. **Смысловая цепочка (замена одной буквы):** Прочти цепочку, где меняется только гласная: *bad ➔ bed ➔ bid ➔ bod ➔ bud*.
2. **Замена первого согласного:** Прочти цепочку рифм: *cat ➔ bat ➔ fat ➔ hat ➔ mat ➔ rat*.
3. **Замена конечного согласного:** Прочти цепочку: *pan ➔ pat ➔ pad ➔ pet ➔ pen*.
4. **Скоростное чтение таблицы (30 слов):** Засеки секундомер и прочти 30 слов на время:
   *cat, bed, sit, hot, cup, red, big, dog, sun, pen, box, bus, hat, ten, lip, fox, run, bat, pet, six, top, nut, bag, net, win, pot, bug, man, leg, van*.
5. **Соединение слова с картинкой/смыслом:** Соедини: *pen* (ручка), *dog* (собака), *cup* (чашка), *box* (коробка), *sun* (солнце).
6. **Поиск бессмысленного псевдослова (Non-word test):** Найди в списке несуществующее слово: *cat, dog, mab, sun, pen*. (Проверка чистоты навыка чтения букв!).
7. **Чтение первых мини-фраз:** Прочти вслух:
   - *A big cat.* (Большой кот.)
   - *A red pen.* (Красная ручка.)
   - *A hot cup.* (Горячая чашка.)
8. **Аудио-диктант целых слов:** Запиши 6 слов под диктовку: *cat, pen, sit, dog, bus, red*.

### 5. Ответы
- **Задание 6 (Псевдослово):** *mab* — искусственное проверочное слово (не имеет словарного значения).
- **Задание 7 (Перевод фраз):** 
  - *A big cat* = Большой кот.
  - *A red pen* = Красная ручка.
  - *A hot cup* = Горячая чашка.
- **Задание 8 (Диктант):** 1. cat; 2. pen; 3. sit; 4. dog; 5. bus; 6. red.
