# 🌐 NATIVE Edu — Платформа разговорных языковых курсов

Премиальный, минималистичный и высококонверсионный веб-сервис для продажи авторских языковых курсов (Испанский, Английский, Китайский) и автоматизированного контент-маркетинга.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FMysterio3-8%2FLangNative)

---

## 🚀 Возможности платформы

1. **Современный премиальный дизайн (Apple / Notion EdTech) & Мобильная оптимизация:**
   - Чистая светлая тема без навязчивого визуального шума.
   - Микро-сетка на заднем плане и интерактивные 3D-карточки демонстрации уроков.
   - Полная мобильная адаптация под любые смартфоны (iOS Safari, Android Chrome) с плавным скроллом 60/120 FPS благодаря `content-visibility: auto` и аппаратному ускорению.

2. **Психологически выверенное ценообразование:**
   - 🇪🇸 **Испанский язык (A1–B1):** **290 ₽** (было 1 290 ₽, скидка 78%) — сверхнизкий порог входа, моментальный импульсивный лид-магнит.
   - 🇬🇧 **Английский язык (A1–B2):** **390 ₽** (было 1 690 ₽, скидка 77%) — флагманский продукт (база Oxford 3000 + 365 тестов на слух).
   - 🇨🇳 **Китайский язык (HSK 1–5):** **490 ₽** (было 1 990 ₽, скидка 75%) — премиальный курс с прописями и аудио-тренажёром тонов.
   - 🌟 **Комплект «Все языки (3-в-1)»:** **790 ₽** (было 2 990 ₽, скидка 74%) — максимальный средний чек с выгодой 380 ₽ относительно раздельной покупки.

3. **Интерактивный тренажер (Live Demo):**
   - Реальные тесты на английском, китайском (иероглифы + пиньинь) и испанском прямо в браузере.
   - Подгрузка проверенной базы 2 190+ карточек из `data/demo_quizzes.json` с мгновенным откликом.

4. **Интерактивный ридер программы и уроков (Reader Modal):**
   - Просмотр 20 подробных модулей каждого курса.
   - Чтение полного пробного Урока №1 с разбором разговорных конструкций и чанков.

5. **Юридическая безопасность и защита оператора:**
   - Полный комплект документов: `offer.html` (Оферта и соглашение) и `privacy.html` (Политика конфиденциальности).
   - Соответствие нормам законодательства РФ (ЗоЗПП, ГК РФ, 149-ФЗ, 54-ФЗ, 38-ФЗ, 152-ФЗ, Постановление Правительства № 2463).
   - Идентификационные данные оператора и Shop ID ЮKassa спрятаны в аккуратный сворачиваемый аккордеон.

6. **Защищенная система отзывов с клиентской автомодерацией:**
   - Реальные отзывы (4–5 звёзд) публикуются мгновенно.
   - Критические отзывы (1–3 звезды) уходят на премодерацию владельцу.
   - Заказной спам, ссылки, мат и стоп-слова конкурентов жестко блокируются на входе.

7. **Панель управления администратора (`/admin`):**
   - Защита мастер-PIN кодом (`2026`).
   - Пульт модерации отзывов с фильтрами и действиями в один клик.
   - Журнал реальных заказов с экспортом в CSV и ручным созданием заказов.
   - Редактор цен, синхронизированный с ЮKassa (Shop ID: `1314296`, СБП 0%, МИР).
   - AI-ассистент авто-квалификации входящих лидов (Lead Triage).

8. **Генератор длинных обучающих видеоуроков для YouTube и VK Видео:**
   - Модуль `TelegramMusicSoft/app/vk_poster/language_long_lesson.py` автоматически генерирует 15-минутные Full HD 1080p видеоуроки в день (6 педагогических фаз, дуэт Edge-TTS, Pillow-слайды, NVENC аппаратный рендеринг, авто-таймкоды и SEO-описание).

9. **SEO & Производительность:**
   - Schema.org (EducationalOrganization, Course, Offer) JSON-LD.
   - OpenGraph и Twitter Cards мета-теги.
   - Валидные `robots.txt` и `sitemap.xml`.

## ⚡ Развёртывание на GitHub Pages и Vercel

### Автодеплой в 1 клик
Запустите скрипт:
```bash
python deploy.py "update site"
```
Скрипт автоматически создаст git-коммит и отправит его на GitHub. Обновление сайта на доменах произойдёт за 10–15 секунд.

## 📁 Архитектура проекта
```
courses_site/
├── index.html            # Главный лендинг платформы (семантический HTML5, Microdata)
├── style.css             # Единый оптимизированный мастер-стиль (0 FOUC, 60/120 FPS)
├── offer.html            # Публичная оферта и правила предоставления материалов
├── privacy.html          # Политика конфиденциальности и защиты данных
├── admin.html            # Панель администратора (/admin)
├── admin.css             # Стили панели администратора
├── admin.js              # Логика админки (заказы, модерация, Lead Triage)
├── create_payment.py     # Бэкенд-интеграция платёжного шлюза ЮKassa (API OAuth/Shop ID)
├── deploy.py             # Скрипт автодеплоя в GitHub и Vercel
├── vercel.json           # Роутинг, кэширование и заголовки безопасности
├── robots.txt            # Директивы для поисковых ботов (Яндекс, Google)
├── sitemap.xml           # XML карта сайта
├── js/
│   ├── common.js         # Базовые утилиты, аккордеон FAQ, плавный скролл, куки
│   ├── trainer.js        # Движок интерактивного онлайн-тестирования
│   ├── checkout.js       # Оформление заказа, модальное окно, валидация и ЮKassa
│   ├── reviews.js        # Модуль отправки отзывов и автомодерации
│   └── reader.js         # Интерактивный просмотрщик программы курса и Урока 1
├── data/
│   ├── courses.json      # Официальные цены, скидки, выгода и описания
│   ├── demo_quizzes.json # База 2 190+ карточек для тренажёра
│   ├── course_previews.json # Программы всех 20 уроков и полный текст Урока 1
│   ├── faq.json          # База вопросов и ответов
│   └── reviews.json      # Одобренные отзывы студентов
└── assets/
    └── branding/         # Фирменные аватары курсов и логотип проекта
```
