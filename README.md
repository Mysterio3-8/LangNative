# 🌐 NATIVE Edu — Платформа разговорных языковых курсов

Премиальный, минималистичный и высококонверсионный веб-сервис для продажи авторских языковых курсов (Английский, Китайский, Испанский и Combo 3-в-1).

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FMysterio3-8%2FLangNative)

---

## 🚀 Возможности платформы

1. **Современный премиальный дизайн (Apple / Notion EdTech):**
   - Чистая светлая тема без навязчивого визуального шума.
   - Микро-сетка на заднем плане и 3D-карточки демонстрации уроков.
   - Полная мобильная адаптация под смартфоны и планшеты.
2. **Интерактивный тренажер (Live Demo):**
   - Реальные тесты на английском, китайском (иероглифы + пиньинь) и испанском языках прямо в браузере.
   - Подгрузка проверенной базы 2 190+ карточек из `data/demo_quizzes.json`.
3. **Защищенная система отзывов с ИИ-автомодерацией:**
   - Честные отзывы (4–5 звёзд) публикуются мгновенно.
   - Критические отзывы (1–3 звезды) уходят на премодерацию владельцу.
   - Заказной спам, ссылки, мат и стоп-слова конкурентов («лохотрон», «скам», «параша» и др.) жестко блокируются на входе.
4. **Админ-панель (`/admin`):**
   - Пульт модерации отзывов с фильтрами и действиями в один клик.
   - Журнал заказов с экспортом в CSV.
   - Управление ценами (249 ₽ за язык, 499 ₽ комбо).
   - Интеграция шлюза ЮKassa (Shop ID `1314296`, СБП 0%, МИР).
   - AI-ассистент авто-квалификации лидов (Lead Triage).
5. **SEO & Производительность:**
   - Schema.org (EducationalOrganization, Course, Offer) JSON-LD.
   - OpenGraph и Twitter Cards мета-теги.
   - Валидные `robots.txt` и `sitemap.xml`.

## ⚡ Развёртывание на Vercel

### Способ 1. Автоматический деплой через GitHub (Рекомендуется)
1. Откройте [vercel.com/new](https://vercel.com/new)
2. Выберите репозиторий `Mysterio3-8/LangNative`
3. Нажмите **Deploy** — Vercel автоматически соберет и опубликует проект за 15 секунд с бесплатным SSL-сертификатом и глобальным CDN.
4. При каждом вашем `git push` сайт будет автоматически обновляться.

### Способ 2. Через Vercel CLI
```bash
npm i -g vercel
vercel login
vercel --prod
```

## 📁 Структура проекта
```
courses_site/
├── index.html            # Главный лендинг платформы
├── style.css             # Стили дизайн-системы NATIVE
├── app.js                # Клиентская логика, демо-тесты и автомодерация
├── admin.html            # Панель управления и модерации (/admin)
├── admin.css             # Стили панели администратора
├── admin.js              # Управление заказами, ценами и отзывами
├── vercel.json           # Конфигурация маршрутизации и безопасности Vercel
├── robots.txt            # Директивы для поисковых роботов
├── sitemap.xml           # Карта сайта для Google и Яндекс
├── data/
│   ├── demo_quizzes.json # База интерактивных вопросов
│   ├── reviews.json      # База проверенных отзывов
│   └── courses.json      # Метаданные курсов
└── assets/
    └── branding/         # Фирменные аватары и логотипы
```
