## ⚡ Как открыть и протестировать локально
Просто дважды кликните по файлу `courses_site/index.html` — сайт откроется в любом браузере (Chrome, Edge, Яндекс).

## 🌍 Как запустить на одном домене (3 бесплатных способа):

### Вариант 1. Vercel или Netlify (Самый быстрый, 1 минута)
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Просто перетащите папку `courses_site` в окно браузера.
3. Сайт моментально станет доступен по бесплатному адресу (например, `lingohub.netlify.app`), к которому можно привязать любой свой домен.

### Вариант 2. GitHub Pages (Бесплатно навсегда)
1. Загрузите файлы в репозиторий GitHub.
2. В настройках репозитория (Settings → Pages) включите ветку `main`.
3. Сайт будет работать по адресу `ваш-ник.github.io/название-репо/` или на вашем домене.

### Вариант 3. Встроить прямо в паблики ВКонтакте (VK Mini App / Меню группы)
1. Ссылку на сайт можно поставить в кнопку действия сообщества (например, **«Купить курс»** или **«Открыть сайт»**).
2. Также можно загрузить как VK Mini App через платформу VK Developers.
